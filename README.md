# 🧾 Bill & Warranty Tracker

A simple and efficient web application to manage **purchase bills** and **product warranty information**. Built with **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**, this application helps users organize their purchased products and keep track of warranty expiration dates.

---

## 📌 Features

- ➕ Add new products with purchase details
- 🧾 Store bill/invoice information
- 📅 Track warranty start and expiry dates
- 📋 View all saved products
- ✏️ Edit existing records
- 🗑️ Delete unwanted records
- 💾 SQLite database for persistent storage
- 🌐 Clean and user-friendly interface

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Bill-Warranty-Tracker.git
```

### 2️⃣ Navigate to the Project

```bash
cd Bill-Warranty-Tracker
```

### 3️⃣ Install Dependencies

```bash
pip install flask
```

### 4️⃣ Run the Application

```bash
python app.py
```
